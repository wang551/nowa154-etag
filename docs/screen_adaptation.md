# 152×152 屏适配逆向推导

> 记录把上游 1.54" 驱动（按 200×200 几何编写）适配到 Nowa-154R-N 实际
> 152×152 玻璃的完整过程。方法论可复用于其他"屏不亮/内容错位"的价签移植。

## 起点：型号探测失败

上游 `epd.c` 的 `EPD_detect_model()` 无法区分 1.54" 和 2.13"（154 控制器对 213
探测序列的响应相同，epd.c 注释已说明），导致固件实际按 BWR213（250×128 长方形）
输出：正方形屏只显示内容右侧一部分，底部空白。

本 fork 的处理：`EPD_detect_model()` 末尾**强制 `epd_model = 3`**（BWR154）。
代价是失去多型号自动探测——这是专机专用 fork，可接受。

## 四轮实验定栅极映射

修改方式：每轮改 `epd_bwr_154.c` 的 Y 窗口寄存器（0x45）后刷机，观察玻璃上
**实际被刷新的行数与位置**：

| 轮次 | 固件 Y 窗口（RAM 行号） | 玻璃上可见行数 | 现象 |
|---|---|---|---|
| 0 | 上游 213 驱动 46→296 | **152（满宽）** | 内容满宽、底部空 24 行（源极只驱 128/152） |
| 1 | 200×200 版 0→199 | ~56 行 | 左侧约 1/3 黑白花（X 窗口 25 字节溢出）+ 右侧旧内容 |
| 2 | 152 版 0→151 | ~8 行 | 左侧小条 + 残缺数字 |
| 3 | **295→144** | 152（满宽、贴合） | 定版 |

联立唯一解：**玻璃的 152 条栅极线接在控制器 RAM 的 Y 144..295**（控制器是
296/297 线规格，汉朔把 152 线玻璃接在后半段；与 213 驱动的 46..296 偏移同套路）。
源极（X 方向）确认从 0 起无偏移。

> 技巧：内容"整体出现在哪、缺哪"就是窗口对没对上的直接证据；配合画一个
> 贴边边框矩形，肉眼即可判断覆盖与偏移方向。

## 源极方向还有像素级偏移 δ

栅极修正（v3）后左右完美贴合，但内容整体上移、顶部被裁 δ 行、底部空 δ 行：
源极线相对 RAM 位也有偏移。v4/v5 两版参数化实测：

- δ=8：边框四边贴合（**定版**）
- δ=12：曾按"底部空白条 ≈2.2mm"推算，实为误读——**以真机实刷为准**

换算参考：1px = 27.6mm/152 ≈ 0.182mm，即 δ=8 ≈ 1.45mm。

## 最终参数（`Firmware/src/epd_bwr_154.h`）

```c
#define BWR_154_GATE_START 144   // 玻璃栅极线接在 RAM Y 144..295
#define BWR_154_GATE_END   295
#define BWR_154_SRC_OFFSET 8     // RAM bit b 驱动玻璃行 b-8，渲染需整体下移 8px
#define BWR_154_SRC_BYTES  20    // (152+8+7)/8，控制器 RAM 每列字节数
#define BWR_154_CANVAS_H   160   // 渲染画布高（玻璃显示画布第 8..159 行）
```

0x01 深睡计数 0x97（152 gates）、X 窗口 0x00–0x12（19 字节 + 偏移扩到 20）、
0x4F=0x97；写入长度钳位到 2888 字节（BLE 裸缓冲路径传 5000 会溢出窗口回卷）。

## 位序：OBD 是 LSB-first，玻璃是 MSB-first

上游 OneBitDisplay 虚拟缓冲按 `1<<(y&7)`（LSB-first）组织；FixBuffer 的
`~ucMirror[]` 位反转后送控制器，即**控制器 RAM 字节内 MSB-first**。两条路径：

- TIFF/G4 路径（`0x04` 命令）：`TIFFDraw()` 直接 `0x80>>((y+yoff)&7)`，与硬件一致，无需改
- BLE 裸缓冲路径（`0x03` 命令）：需要自己打包（见 [ble_protocol.md](ble_protocol.md)）。
  首版按 LSB-first 打包，真机表现为"每 8 行条带内上下翻转"（W 变 M），改 MSB 后
  三方对拍全等

## 排坑

- **make 不跟踪头文件依赖**：改 `epd_bwr_154.h` 宏后必须 `rm -rf out ATC_Paper.bin`
  全量重编，否则产物 md5 与旧版完全相同（现象是"改了没生效"）
- tc32-elf-gcc 4.5.1 随机 ICE，重跑即可（`tools/build_retry.sh`）
